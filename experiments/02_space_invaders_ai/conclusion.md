
# 🔬 Дослідницький щоденник — Space Invaders AI

**Дата:** 10.10.2026  
**Тема:** Reinforcement Learning із нейромережею на NumPy.

## 1. Мета

Навчити агента грати у Space Invaders. Дослідити принципи Reinforcement Learning через власну реалізацію, експерименти та аналіз помилок.

## 2. Що реалізовано

- Ігрове середовище на Pygame.
- Табличний Q-learning.
- Neural Q-learning із мережею `11 → 16 → 4`.
- Forward propagation та backpropagation на NumPy.
- Epsilon-greedy та TD-target.
- ReLU і Leaky ReLU.
- Система винагород.
- Train / Evaluate / Random.
- Збереження моделей, CSV-логування та діагностика.

## 3. Проведені експерименти

| Експеримент | Результат |
|---|---|
| ReLU | Виявлено Dead ReLU для досліджених станів |
| Leaky ReLU | Проблема нульового градієнта для від'ємних активацій усунута |
| Gamma 0.9 → 0.99 | Покращення політики не підтверджено |
| Terminal states | Виправлено обчислення TD-target через `done` |
| NeuralAgent vs Random | Випадковий агент показав кращі результати |

### Останнє порівняння

| Метрика | NeuralAgent | Random |
|---|---:|---:|
| Убивств/епізод | 3,05 | 4,10 |
| Середній час виживання | ~27,5 с | ~30,8 с |
| Частка дій `shoot` | 94,73% | ~25% |

## 4. Висновки

1. Оновлення ваг нейромережі не гарантує покращення політики.
2. Неправильна обробка термінальних станів спотворює TD-target.
3. Відкладена винагорода ускладнює credit assignment.
4. Агент схильний до домінування однієї дії.
5. Високий learning rate може спричиняти числову нестабільність.
6. Складне середовище ускладнює діагностику алгоритму.

**Головний результат:** реалізовано працездатний Neural Q-learning, але ефективне навчання політики поки не підтверджено.
